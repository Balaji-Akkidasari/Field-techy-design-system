    22.1 Implementation notes
    
    
      
      
    • Load Poppins (400/500/600/700/900), Inter (400–700), Rubik (600), Plus Jakarta Sans (800). Replace all Segoe UI text with Poppins.
      • 
      
    • One <Button> primitive: variants primary | dark | outline | approve | reject | social, sizes lg (47) | md (48), fullWidth, trailing icon 20 pt.
      • 
      
    • Bottom nav: 4 slots, active prop → #009966.
      • 
      
    • Base Card: white, radius 16, border #D7DAE6, pad 16–24.
      • 
      
    • Wallet card: gradient fill + white Rubik amount.
      • 
      
    • Dark mode is not designed in v2.0 — keep light theme.
      • 
      
    • Text may expand ~30% for localization — avoid fixed-height text boxes.

    Login animation
    
      Handoff
    
    
    
    The 7-state splash loop from Login animation v1.0 mobile as a single production-ready JSON. Frames are embedded inline — all on a fixed 400×400 stage — so a developer can drop this file in and render the loop without touching assets.

    23.1 How to render it
    
    
      
      
    • Parse the JSON — stage is the fixed 400×400 canvas; states[].svg is the frame markup ready to inject.
      • 
      
    • Crossfade states every 2000 ms over 300 ms ease (see timing), apply the float to the active state, and fill the background gradient.
      • 
      
    • Respect reducedMotion — keep cross-fades, drop the float.
      • 
      
    • Source: Figma component Login animation v1.0 mobile · frames 1450:78964–1450:79353.
